Protection Layers

Two obfuscation engines fused into one — stream cipher + bytecode VM running in parallel.

Dual-Engine VM

Combines stream-cipher string encryption with full bytecode virtualization. Two layers that work independently — break one, the other holds.

String Obfuscation

Every string is encrypted with a rolling XOR cipher seeded by a unique 44-bit state. Decryption keys are never stored — they are computed at runtime.

Bytecode Virtualization

Lua 5.1 and 5.4 bytecode is compiled into a randomized virtual instruction set with shuffled opcodes on every run.

Per-Run Randomization

Opcode map, key seeds, tag encodings and alphabet are re-randomized each obfuscation. No two outputs are identical — even for the same input.

Constant Pool Encryption

Numeric and string constants are encrypted in the bytecode payload with a streaming key. Constants never appear in plaintext in the output.

Control Flow Obfuscation

Branch logic is flattened into a weighted dispatch tree using product-key encoding. Static analysis cannot reconstruct the original flow graph.

How It Works

01

Parse

Lua source compiles to bytecode. Parser reads Lua 5.1 or 5.4 chunk format — opcodes, constants, upvalues, proto tree.

02

Encode

Bytecode stream is encrypted with a rolling key cipher. Opcodes are remapped to a shuffled virtual instruction set.

03

Embed VM

A self-contained Lua VM is generated with randomized variable names and dispatch tree, then bundled with the encrypted payload.

04

Output

Final output runs identically to the original while being resistant to static analysis, decompilation, and string extraction.
